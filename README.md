# Ice Cream Hit

A knife hit inspired game where your objective is to hit ice cream!

<img width="289" height="515" alt="image" src="https://github.com/user-attachments/assets/6c5a0c30-b145-46db-908a-fe741e648475" />

The game is made in Unity using C# and [released on itch.io](https://5tr4w6.itch.io/icecream-hit)

## Levels
- Strawberry
- Chocolate
- Candy
- Angel
___

All sprites were made by me using Krita and music produced in Bandlab.
